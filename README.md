# Telco Customer Churn Analysis — 500 Customers

## Files
- `telco_500_raw.csv` — raw dataset with intentional missing values and duplicates
- `telco_500_cleaned.csv` — cleaned final dataset with 500 unique customers
- `Telco_500_Customer_Churn_Analysis.ipynb` — complete analysis notebook
- `Telco_500_Insights_Report.md` — short report with exact calculated findings
- `iqr_outlier_analysis.csv` — IQR calculations and outlier counts
- `visualizations/` — 8 generated charts

## Main Tasks
1. Data understanding
2. Data type checking
3. Missing-value analysis
4. Duplicate detection
5. Data cleaning
6. IQR outlier analysis
7. Exploratory data analysis
8. Eight visualizations
9. Business insights
10. Business recommendations
